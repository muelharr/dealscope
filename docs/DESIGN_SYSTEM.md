# Design System

DealScope utilizes a specialized variant of Material 3 principles.

## Colors
- **Primary:** `#0050cb`
- **Surface:** `#faf8ff` (light mode base)
- **Positive:** `#10B981`
- **Caution:** `#F59E0B`
- **Negative:** `#EF4444`

## Typography
- **Inter:** Primary font for UI labels and body text.
- **JetBrains Mono:** Strictly for pricing and financial data.

## Rounded Scale
- **Default:** 8px
- **xl:** 12px
- **full:** 9999px
