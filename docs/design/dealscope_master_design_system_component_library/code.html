UX Patterns

search Search & Discovery

Users begin with the global search bar. Predictive results suggest specific models and categories. The results page prioritizes "Best Deal" badges based on DealScope score.

"A search should never lead to an empty state; always suggest similar products or historical trends if the specific item is out of stock."
notifications_active Alert Triggers

Setting a price alert is a primary conversion. The flow includes: 1. Price Threshold Setting, 2. Channel Selection (Email/App), 3. Confirmation Toast.
