schema Core Principles

  • 01

    Functional First

    Animations must serve a purpose: state change, continuity, or hierarchy.

  • 02

    Non-distracting

    Micro-interactions should be felt, not necessarily observed as "effects".

  • 03

    Performance-driven

    Prioritize transform and opacity properties to hit 60fps on low-end devices.
